\chapter*{Foreword}
\addcontentsline{toc}{chapter}{Foreword}

This material is intended to be used as a guide for an introduction to parallel programming in C++. The course is designed to provide a comprehensive understanding of the concepts and techniques related to parallel programming in C++. The material is structured in a way that allows for a gradual introduction of the topics, starting from the basics and progressing towards more advanced concepts.

For a full reference on the C++ programming language and its standard library, please refer to the C++ reference documentation~\cite{cppreference}. For basic understanding of the C++ programming language, please refer to the books \emph{``A Tour of C++''}~\cite{stroustrup:2022} and \emph{``Programming: Principles and Practice Using C++''}~\cite{stroustrup:2024}.

The parallel ranges library is a very recent addition to the C++ standard library, and it is still in the process of being adopted by compilers and libraries. The specification can be found in the paper~\cite{parallelrng:2025}.
